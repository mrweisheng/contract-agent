# 小程序用户登录 + 头像接口说明

小程序端用户体系：微信一键登录（静默）、手机号绑定、昵称/头像资料。与「对外合同查询接口」互相独立：查询合同仍用 `X-API-Key`，用户接口只认登录 token。

## 服务地址

生产环境：`https://contract.eazycar.top`（HTTPS 443）

完整地址 = 服务地址 + 路径，例如登录为 `https://contract.eazycar.top/api/auth/wx-login`。小程序后台「开发管理 → 服务器域名」需把 `contract.eazycar.top` 加入 **request / uploadFile** 合法域名（头像走 `wx.uploadFile`）。

## 鉴权

- 服务端配置环境变量 `WX_APPID` / `WX_APP_SECRET`（**未配置时整个登录前缀返回 503，即对外关闭**）；Secret 只放服务端，绝不发给前端
- 登录成功返回不透明 token（30 天有效）；后续请求带 Header：`Authorization: Bearer <token>`
- token 存库可吊销；过期/未登录返回 401

## 接口

### 1. 静默登录（一键登录）

```
POST /api/auth/wx-login
Content-Type: application/json

{"code": "<wx.login() 拿到的 code>"}
```

- 前端：小程序启动时 `wx.login()` 取 code 发上来；`code` 一次性、5 分钟有效
- 服务端调微信 `jscode2session` 换 `openid`，按 openid 定户，**首次登录自动建户**（昵称头像为空）
- 返回：

```json
{"token": "…", "expires_in_days": 30,
 "user": {"id": 1, "nickname": "", "phone": "", "avatar_url": "",
          "role": "user", "role_label": "普通用户", "created_at": "…"}}
```

- `role` 三档：`user` 普通用户（默认）/ `admin` 管理员 / `super` 超级管理员；`role_label` 是中文名，前端可直接显示
- 微信侧 code 无效等错误返回 401；每次启动重复调用即可，天然续期（每次发新 token）

### 2. 绑定手机号（两种方式二选一）

```
POST /api/auth/phone
Authorization: Bearer <token>

{"code": "<getPhoneNumber 按钮的 code>"}   // 方式 A：手机号快速验证组件（需企业认证小程序，微信按次收费）
{"phone": "13800138000"}                    // 方式 B：用户手动输入提交
```

返回 `{"ok": true, "user": {…}}`。`phone` 手动提交须为 8-15 位纯数字（大陆 11 位、香港 8 位），否则 422。**未授权手机号不能签署合同**（提交签名时返回 403），签署后合同绑定到该登录账号。

### 3. 我的资料

```
GET /api/users/me
Authorization: Bearer <token>
```

返回同登录里的 `user` 结构。

### 4. 改昵称

```
PATCH /api/users/me
Authorization: Bearer <token>

{"nickname": "陈大文"}
```

1-30 个字符，超长/为空返回 422。前端输入框建议用 `type="nickname"`（微信一键填昵称）。

### 5. 上传头像

```
POST /api/users/me/avatar
Authorization: Bearer <token>
```

**三种请求体任选其一**（按 Content-Type 自动识别）：

| 方式 | Content-Type | 请求体 | 适用 |
|---|---|---|---|
| multipart | `multipart/form-data` | 文件字段名 `file` 或 `image` | `wx.uploadFile` 传 `chooseAvatar` 临时文件 |
| 裸字节 | `image/png` 或 `image/jpeg` | 图片二进制 | `wx.request` arraybuffer |
| dataurl | `application/json` | `{"image": "data:image/png;base64,…"}` | 与签名回传同风格 |

- 原图限 PNG/JPG、≤5MB；服务端**方形居中裁剪重编码 512×512 JPEG**（洗掉 EXIF 与注入内容）
- 返回 `{"ok": true, "user": {…}}`，`avatar_url` 自带版本参数（`?v=2`），重复上传自动破缓存

### 6. 读取头像

```
GET /api/users/{user_id}/avatar
```

返回 512×512 JPEG。**无需鉴权**（小程序 `<image>` 标签带不了鉴权头；仅一张方图无敏感信息）。未设置返回 404。资料里的 `avatar_url` 是**完整 https 地址**（由请求的 `X-Forwarded-Proto`/`Host` 推出，如 `https://contract.eazycar.top/api/users/1/avatar?v=2`），小程序直接赋给 `<image src>` 即可，不需要再拼域名。

### 7. 登出（吊销 token）

```
POST /api/auth/logout
Authorization: Bearer <token>
```

返回 `{"ok": true}`；幂等，token 不存在也返回 ok。登出后该 token 立即失效，同用户其他设备发出的 token 不受影响。

### 8. 角色（后台管理用）

角色三档：`user` **普通用户**（所有新用户默认）、`admin` **管理员**、`super` **超级管理员**。权限细则后续再定，目前只落角色与展示。

```
GET   /api/users?keyword=&limit=200        # 用户列表（含 role / role_label，并附 roles 字典与 default_role）
PATCH /api/users/{id}/role                 # 改角色（内部后台调用，测试期不做鉴权）
      {"role": "admin"}                    # user / admin / super，其它值 422；用户不存在 404
```

- 登录成功返回的 `user` 里已带 `role` / `role_label`，小程序据此判断展示与可用功能
- 复登、改昵称头像、上传头像都不会重置角色
- 工作台「用户管理」页面可直接在下拉里改角色，改完即时生效
- 用户列表每行附脱敏 `openid`（前 6 + 后 4）与完整 `openid_full`：「微信标识」列默认只显示脱敏值，点击展开完整值并自动复制、再点收回，用于和微信侧对账。该接口是内部管理用途，不要直接暴露到公网

## 调用示例（小程序）

```js
const BASE = 'https://contract.eazycar.top';

// 1. 启动即静默登录（code 一次性）
wx.login({
  success: ({ code }) => wx.request({
    url: `${BASE}/api/auth/wx-login`,
    method: 'POST',
    header: { 'Content-Type': 'application/json' },
    data: { code },
    success: (res) => {
      wx.setStorageSync('token', res.data.token);
      wx.setStorageSync('user', res.data.user);
    }
  })
});

// 2. 之后所有请求带 Bearer
const token = wx.getStorageSync('token');
wx.request({ url: `${BASE}/api/users/me`, header: { Authorization: `Bearer ${token}` } });

// 3. 改昵称
wx.request({
  url: `${BASE}/api/users/me`, method: 'PATCH',
  header: { Authorization: `Bearer ${token}`, 'Content-Type': 'application/json' },
  data: { nickname: '陈大文' }
});

// 4. 上传头像（chooseAvatar 按钮拿到的临时文件；字段名 file 或 image）
wx.uploadFile({
  url: `${BASE}/api/users/me/avatar`,
  filePath: tempFilePath,
  name: 'file',
  header: { Authorization: `Bearer ${token}` }
});

// 5. 绑定手机号（getPhoneNumber 按钮的 code）
wx.request({
  url: `${BASE}/api/auth/phone`, method: 'POST',
  header: { Authorization: `Bearer ${token}`, 'Content-Type': 'application/json' },
  data: { code: phoneCode }
});

// 6. 登出（吊销当前 token）
wx.request({
  url: `${BASE}/api/auth/logout`, method: 'POST',
  header: { Authorization: `Bearer ${token}` }
});
```

头像读取：返回的 `user.avatar_url` 已是完整 https 地址（如 `https://contract.eazycar.top/api/users/1/avatar?v=2`），直接给 `<image src>` 即可。

## 我的合同（签署即绑定 / 示例合同）

正式合同生成时是**无主**的；客户提交手写签名成功的那一刻**自动绑定当前登录用户**（没有二次确认步骤），状态变为已签署。
绑定后：**本人可见**、管理员在工作台/对外 key 接口可见，**其他登录用户一律 404**。

列表按角色分两种口径：

| 角色 | `GET /api/users/me/contracts` 返回 |
|---|---|
| 普通用户 `user` | 本人已签合同 + **一份示例合同**（首次查询时自动生成） |
| 管理员 `admin` / `super` | 可见范围内**全部正式合同**（`2026-11-22` 起，与对外接口同口径），不含示例合同 |

示例合同（2026-11-23）：

- 业务＝卖车，结构与正式卖车合同完全一致，客户信息固定为「测试用户」；
- 编号以 `9` 开头（11 位），与正式合同 `YYYYMMDD` 编号不可能撞号；
- **每个普通用户独立一份**：A 签了不影响 B，A 的签名不会出现在 B 的示例里；
- 可正常看详情（blocks）、下载、提交签名（仍需先绑定手机号）；
- 不进工作台合同列表、最近生成、对外查询接口（`is_sample` 标记过滤）。

| 用途 | 方法 | 路径（前缀 `https://contract.eazycar.top`） |
|---|---|---|
| 我的合同列表 | GET | `/api/users/me/contracts` |
| 单份详情（blocks） | GET | `/api/users/me/contracts/{no}` |
| 下载已签版 docx | GET | `/api/users/me/contracts/{no}/file` |
| 客户签名图 | GET | `/api/users/me/contracts/{no}/signature` |
| 提交手写签名 | POST | `/api/users/me/contracts/{no}/signature` |

全部走 `Authorization: Bearer <token>`，body 与对外接口的签名回传一致（`{"image": "data:image/png;base64,..."}`）。

规则：

- **未授权手机号不能签**：先调 `/api/auth/phone` 绑定手机号，否则 403「请先授权手机号再签署」
- 同一份合同只能签一次：本人重复签、被他人抢先签 → 409
- 一个账号可以绑定多份合同（一客户多单）
- 示例合同签完后仍留在本人列表里（状态变为已签），但**不会**变成公共签章：其他用户看到的仍是各自未签的示例
- 客户名与微信昵称不一致属正常情况，不做校验
- 他人合同按「不存在」处理（404），不提示历史/归属信息

```js
// 签署：成功后自动绑定，无需再调其它接口
wx.request({
  url: `${BASE}/api/users/me/contracts/${no}/signature`,
  method: 'POST',
  header: { Authorization: `Bearer ${token}`, 'Content-Type': 'application/json' },
  data: { image: dataUrl }
});

// 我的合同列表
wx.request({
  url: `${BASE}/api/users/me/contracts`,
  header: { Authorization: `Bearer ${token}` },
  success: (res) => { /* res.data.items */ }
});
```

## 前端对接建议（登录流程）

1. `app.js` 启动：`wx.login()` → 调接口 1 → token 存本地缓存（`wx.setStorageSync`），后续请求带 Bearer 头
2. 「我的」页：接口 3 渲染资料；头像用 `open-type="chooseAvatar"` 按钮 + 接口 5；昵称用 `type="nickname"` 输入框 + 接口 4
3. 需要手机号时（如关联合同）：`open-type="getPhoneNumber"` 按钮 → `code` → 接口 2 方式 A；未认证小程序退化为输入框 + 接口 2 方式 B

## 部署注意

- 服务端 `.env` 增加 `WX_APPID=<小程序 AppID>` 与 `WX_APP_SECRET=<小程序 Secret>`；**不配置则登录接口整体关闭**（503）
- `requirements.txt` 本次新增 `pillow==12.3.0`、`python-multipart==0.0.34`，部署时需 `pip install -r requirements.txt`
- 头像文件落 `data/uploads/avatars/`（服务端自管，无外部路径参数）；小程序后台「开发管理→服务器域名」需把本服务域名加入 request/uploadFile 合法域名
