## 2026-10-10 之后新增／被纠正的口径（这些是 01–05 里没有的）

1. **汇率分部分套用**：合同内款项按合同给的等值原样取用（不重折），合同外杂费／政府收费／客户垫付按制单当天百度实时汇率；两个口径不互相验算。
2. **汇率精度取 5 位小数**（1.17263，不是百度显示的 1.1726）。
3. **严禁混币种直接相减**：跨币种抵扣必须先按汇率折成同一币种再加减（「面值直减」做法已废弃）。
4. **每单必检**：交付前逐条过检查清单，检查要有结论说给用户听，不能静默通过。
5. **×1.01 只做不说**：单据纸面不得出现「×1.01」「收款系數」等字样。
6. **存底 JSON 内部备忘用下划线私有键**（`_memo` 等）；顶层 `note` 会印到客户单据上。
