# 明哥｜结算单字段格式

用户可按以下格式发送。无需删除不适用项目，填写“无”或“0”即可。

```text
业务类型：〔现牌结算单／新办结算单／车辆买卖结算单〕
群名：〔填写群名〕
客户：〔客户名称〕
日期：〔YYYY年M月D日〕
口岸：〔口岸；车辆买卖可填无〕
结算类型：〔新办／收定金／收第二期款／收尾款／补款／其他〕

合同内总费用。
总价：〔金额＋币种〕

合同内已收费用。
定金：〔金额＋币种；没有填0〕
第二期款：〔金额＋币种；没有填0〕

合同内未收。
〔第二期款／车牌尾款／车辆尾款／其他项目〕：〔人民币金额；如有港币等值，写¥金额／$金额〕

合同外杂费明细。
〔项目〕：〔金额＋币种〕

合同外杂费实收。
〔已收项目名称〕：〔金额＋币种；没有填0〕

合同汇率或合同签订日：〔如已提供双币等值，可留空〕
```

双币写法“¥18000／$21060”表示同一笔款项，不是两笔收款。政府收费只有类别没有金额时，不参与求和。
