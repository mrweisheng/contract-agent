# 明哥｜客户历史档案规则

每张结算单对应一条客户历史记录。只保存制作和追溯结算单所需的信息，不保存无关聊天内容。

## 保存字段

- 客户名称、群名、业务类型、口岸
- 合同总价、已收明细、未收明细
- 合同外杂费及实收
- 结算类型、本次应收人民币、港币口径
- 合同签订日或汇率口径
- PDF文件名、PNG文件名
- 版本状态：PDF待确认、需要修改、已确认、图片已交付
- 创建时间、更新时间

## 更新规则

1. 新单建立新记录。
2. 修改不覆盖旧版本，保留旧版本并将最新版标记为当前版本。
3. 用户确认后把当前版本标记为“图片已交付”。
4. 查询历史时，只引用同一客户和同一业务的相关记录，不把其他客户数字带入当前单据。
5. 历史记录只作复用和核对参考，不能覆盖本次用户最新提供的数字。
