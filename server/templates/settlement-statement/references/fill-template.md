# 收款结算单业务资料填写模板

请直接填写方括号内容；不用删除选项。金额请同时写明币种。没有项目可填写 `无`，合同外杂费实收没有金额时填写 `0`。

```text
业务类型：〔现牌结算单／新办结算单／车辆买卖结算单〕
群名：〔填写群名〕
结算类型：〔新办／收定金／收第二期款／收尾款／补款／其他〕

合同内总费用。
总价：〔金额＋币种〕

合同内已收费用。
定金：〔金额＋币种；没有填 0〕
第二期款：〔金额＋币种；没有填 0〕

合同内未收。
〔第二期款／车牌尾款／车辆尾款／其他项目名称〕：〔人民币金额；如合同同时给出港币等值，请写“¥金额／$金额”〕
〔如有另一笔未收款，在此继续逐笔填写；没有可删除本行〕

合同外杂费明细。
政府收费：
批文卡：260元港币
禁区纸：744元港币
核证本：300元港币
其他杂费：〔项目、金额＋币种；没有填 无〕

合同外杂费实收：〔金额＋币种；没有填 0〕

合同汇率或合同签订日（选填）：〔如已提供合同款双币等值金额，可留空〕
```

## 可选项说明

- `业务类型`三选一：现牌结算单、新办结算单、车辆买卖结算单。
- `结算类型`可直接选用：新办、收定金、收第二期款、收尾款、补款、其他。
- 未收项目可新增多笔，每笔可选第二期款、车牌尾款、车辆尾款，或填写其他项目名称。
- 只需填写与本次业务相关的项目；不要为了套格式修改项目名称。
