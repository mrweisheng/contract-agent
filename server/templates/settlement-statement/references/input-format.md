# 固定输入格式与解析

## 标准段落

用户后续通常按以下顺序发送：

```text
群名：<群名>
客户：<客户名称>
结算类型：<结算类型>
合同内总费用。
<项目>：<金额><币种>
合同内已收费用。
<项目>：<金额><币种或从上下文继承>
合同内未收。
<项目1>：<人民币金额>/<港币等值金额，或单币种金额>
<项目2>：<人民币金额>/<港币等值金额，或单币种金额>
合同外杂费明细。
<类别>：
<项目>：<金额><币种>
合同外杂费实收。
<已收项目名称>：<金额，必要时含币种>
```

段落标题决定其后项目的会计含义，直到遇到下一个段落标题：

- `合同内总费用`：合同应收。
- `合同内已收费用`：合同已收，计算时从同币种合同应收扣减。
- `合同内未收`：用户或合同明确给出的本次合同内应收款，可连续列出多笔。若同一笔同时给出人民币与港币等值，明细只按人民币列一次，港币金额用于汇总并写入备注。
- `合同外杂费明细`：合同外应收。
- `合同外杂费实收`：合同外已收，从同币种合同外应收扣减。项目名称可由用户手动填写，结算单扣减行沿用该名称。

看板会按业务类型预填常用杂费，但这些只是可编辑默认项：两地牌预填批文卡、禁区纸、核证本；购车预填过户、保险、牌费。

`政府收费`等只有类别名称、没有金额的行作为分组标题，不参与求和。

## 文本容错

- 忽略行尾反斜线、HTML 空格、重复空行及标题末尾的句号。
- 冒号可以是 `：` 或 `:`。
- `人民币`、`RMB`、`CNY`、`元人民币`视为 CNY；`港币`、`港元`、`HKD`、`元港币`视为 HKD。
- `18万`解析为 `180000`；`5万`解析为 `50000`；带逗号或两位小数的数字保留其数值含义。
- 项目未重复写币种时，只能从同一段落内明确的币种语境继承。例如车牌总价已注明人民币，紧随其后的定金和第二期款可继承人民币。
- `合同外杂费实收：0`表示所有已列合同外杂费均未收；无需追问币种。
- `合同外杂费实收。旧车通车费用：5000港币`等写法表示以用户填写的具体名称记录该笔已收款；结算单使用该名称显示负数扣减。旧格式只有总数而没有名称时，可回退使用“合同外杂费已收”。
- `¥18000/$21060`、`18000人民币/21060港币`等斜线双币写法表示同一款项的两种等值金额，不是两笔应收。
- 看板也可使用 `¥18000，$21060` 的逗号双币写法；含义与斜线写法相同。

## 固定计算顺序

对每一个币种 `c`：

```text
合同内余额[c] = 合同内总费用[c] - 合同内已收费用[c]
合同外余额[c] = 合同外杂费明细[c] - 合同外杂费实收[c]
本次应收[c] = 合同内余额[c] + 合同外余额[c]
```

多币种汇算：

```text
总计人民币 = 本次应收人民币 + 本次应收港币 ×（1 HKD 对 CNY 汇率）
总计港币 = 本次应收港币 + 本次应收人民币 ×（1 CNY 对 HKD 基准汇率）× 1.01
```

两条基准汇率必须来自同一基准，其中一条为另一条的倒数。`1.01` 仅应用于人民币转港币的最终收款换算，不属于基准汇率。内部计算至少保留 6 位小数；面向客户展示和收款时统一截去小数部分并显示为 `.00`，不得四舍五入。若用户已经提供最终港币金额或明确要求不乘 `1.01`，按用户最新明确指示处理，不得重复加乘。

## 输出核对清单

输出或制单前逐项确认：

1. 群名和结算类型已识别。
2. 每个金额均归入正确段落和币种。
3. 合同内总费用没有被误计入“本次应收”两次。
4. 已收费用均以扣减处理。
5. 合同外实收为零时没有误扣杂费。
6. 内部核算保留原币种余额；结算单汇总区只显示“您今日需付：”及两种统一币种付款口径。
7. 汇率记录完整，双向基准汇率互为倒数；人民币转港币时已乘 `1.01`，并在备注记录该计算口径。
8. 客户展示金额的小数部分已统一截去并显示为 `.00`，未进行四舍五入；内部精确值与展示值的差异已留痕。
8. 金额分位栏已删除左侧无意义的前导 0，且角、分仍保留两位。
9. 同一笔合同未收款项只列一次。默认按人民币列示，港币等值仅在统一付款总额中使用。
10. 用户明确提供同一款项的人民币和港币金额时，备注同时记录两种金额，并固定写入“汇率核算以合同签订日为标准。”
11. 首次交付只展示 PDF 预览；用户确认最新版本后才导出 PNG。若用户同时提出修改，不得视为确认。
