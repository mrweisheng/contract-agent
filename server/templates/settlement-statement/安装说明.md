# 明哥中港牌 · 收款结算单 SKU 安装包 v2.2.0（Mac / Windows 双平台）

给同事拿到就能用的一份完整链路：**能力 + 数据一起给**——规则、铁律、工作流、模板、录入看板、生成引擎，连真实历史单（`data/statements/` 引擎原始 JSON、`data/customer-archives/` 客户档案、`output/` 成品 PDF 与 PNG）都在里面。

**装好以后，发一句「开始」就能开录入看板；贴一段业务资料就能出单。**

---

## 一、三步装好

### 第 1 步：解压

把 `mingge-settlement-statement-v2.2.0.zip` **完整解压**到任意目录，例如
`D:\明哥中港牌\收款结算单\` 或 `~/Documents/明哥中港牌/收款结算单/`。
解压后根目录叫 `settlement-statement`，**进去一层**再执行下面的命令。

> ⚠️ 一定要"解压到文件夹"，不要直接在压缩包里双击运行；中文路径没问题，引擎已按 UTF-8 处理。

### 第 2 步：装运行环境（只做一次）

#### Windows（同事这台）

**双击 `install.bat`** 就行。它会自动：找 Python 3 → 建包内 `.venv` → 装 `reportlab` + `pypdfium2` → 跑自检。
看到 `全部通过，可以开始制单。` 就装好了（窗口会停住等你按键）。

如果双击被安全策略拦了，就用 PowerShell 手动跑：

```powershell
cd <解压出来的 settlement-statement 目录>
powershell -NoProfile -ExecutionPolicy Bypass -File install.ps1
```

**没装 Python 的话**：去 https://www.python.org/downloads/ 下载，**安装时务必勾选 "Add Python to PATH"**，装完重跑 `install.bat`。

#### macOS / Linux

```bash
bash install.sh          # 或双击 install.command
```

#### 顺手注册进 AI 软件（可选）

- Windows：`powershell -NoProfile -ExecutionPolicy Bypass -File install.ps1 -InstallSkill`
- macOS / Linux：`bash install.sh --install-skill`

它把整包复制到 `~/.workbuddy/skills/settlement-statement`，**重启 AI 客户端**后生效
（已存在同名目录时不会覆盖，会提示你手动确认）。

其他 AI 工具（支持 Agent Skills 规范的）：直接把 `settlement-statement` 整个目录
放进它的 skills 目录即可，`SKILL.md` 就是入口，无需改任何文件。

### 第 3 步：验证

- Windows：**双击 `scripts\board.bat`**（或在 PowerShell 里 `.\scripts\board.bat`）
- macOS / Linux：`bash scripts/board.sh`

浏览器会弹出「收款结算单录入看板」。看到看板，就说明装好了。

### 日常制单命令

| 系统 | 一条命令出单 |
|---|---|
| Windows | `scripts\settle.bat --input - --png --clipboard --brief` |
| macOS / Linux | `bash scripts/settle.sh --input - --png --clipboard --brief` |

`--clipboard` 出完图会自动塞进剪贴板：Mac 按 ⌘V、Windows 按 Ctrl+V 就能直接粘到微信。

> **Windows 提示**：PowerShell 管道传中文 JSON 有时会被改编码。稳妥做法是把业务 JSON 先存成文件（UTF-8），再
> `scripts\settle.bat --input 业务.json --png --clipboard --brief`。AI 助手也可以直接用
> `.venv\Scripts\python.exe scripts\make_settlement.py --input 业务.json --png --clipboard --brief`。

## 二、日常怎么用

| 你想做的事 | 说什么 / 做什么 |
|---|---|
| 开一张新单 | 发「开始」「新单」「打开看板」「制作结算单」——直接弹录入看板 |
| 贴资料出单 | 把客户、群名、结算类型、合同总价、已收、未收、杂费、汇率贴给 AI，它一条命令出 PDF + PNG，图自动进剪贴板 |
| 改上一张单 | 说「打开 XXX 那张单」「改 XXX 的单」——AI 从 `data/statements/` 找回原单并还原成可编辑面板 |
| 查客户历史 | 说「查 XXX 的历史」——读 `data/customer-archives/` |

产出位置：PDF 在 `output/pdf/`，PNG 在 `output/image/`，引擎原始输入存 `data/statements/`（改单的唯一依据）。

## 四、已经写死在引擎里的规矩（不用再交代）

这些都是**代码级固化**，同事的 AI 只要按 `SKILL.md` 走就不会跑偏，也不需要他重新教一遍：

- **人民币折港币一律 ×1.01**（`apply_101` 默认 `true`），关掉需要显式填 `false`。
- **「您今日需付」截尾到元、小数固定 `.00`**（不是四舍五入）。
- **×1.01 只做不说**：单据任何文字都不出现「×1.01」。
- **两个币种金额之间必须画 `/`**（`today_sep` 默认 `/`）。
- **结算类型决定本次收款范围**：「收第二期款」不会把尾款算进去，尾款自动降为「下次收款」。
- **已收写客户实付金额**，合同等值只在备注和核算口径里体现。
- **赠送项照价显示但不进合计**。
- **PDF 与 PNG 同一次生成、同时交付**，PNG 自动进剪贴板。
- **有金额冲突先问，不猜**（缺币种、总价对不上、汇率冲突等都写进了 warnings）。

汇率口径（**不是一刀切，是分部分套用**）：
- **合同内款项**（总价/定金/第二期款/尾款）：用户给了双币等值就原样用她的数，**禁止再重折**；她没给就按制单当天的百度实时汇率。
- **合同外杂费 / 政府收费 / 客户垫付**：一律按制单当天的百度实时汇率（人民币→港币再 ×1.01）。
- 两个口径本就用不同汇率，**不要求互相验算**。
- **严禁混币种直接相减**：客户垫付的是港币、要抵扣的是人民币尾款，必须先把港币按当天汇率折成人民币再减（港币口径里减港币、人民币口径里减人民币，跨币种一律先折）。「面值直减」开关已永久禁用。
- **组合积差别慌**：同一单用两套汇率时，会提示「若整单按当日汇率重折为 $205,765，相差 721」——这是合同内不重折导致的正常差异，不是算错。

> ⚠️ 想二次确认某条规则，让 AI 读 `references/铁律速查.md`，一页看完（含「每单必检」清单）。

## 五、两个提醒

1. **包里带的是真实历史单**：`data/statements/`（引擎原始 JSON）、`data/customer-archives/`（客户档案）、`output/`（成品 PDF/PNG）里都有真实客户名和金额。这是有意保留的——同事能直接照着历史单的格式和口径做。**如果只想给能力不带数据**，把这三个目录清空再打包即可，功能不受影响。
2. 版式已经定稿（`assets/收款结算单统一版式基准.pdf` + `SKILL.md`「视觉定稿参数」）。**不要改配色、字号、Logo 位置或恢复旧版式**；要改先跟定版的人确认。
